# 无极仙途国际化翻译大数据监管平台 (Global Localization Workbench v2.0)

> 🎮 **专为游戏出海打造的高保真多语言智能翻译、格式严谨对齐与自动化质检工作台**  
> 具备 **100% 格式符号守恒**、**代码占位符绝对保护**、**多项目独立沙箱隔离** 与 **3D 全息科幻大数据驾驶舱**。

---

## ✨ 核心特性

- 🛰️ **3D 全息科幻大数据驾驶舱**：
  - HTML5 Canvas 3D 旋转粒子地球 + 双向互旋全息轨道光环 + 恒星日出级透镜光晕（Sunrise Lens Flare）。
  - 透视电路板底座地面与疾驰数据流光粒子。
  - 5 大全息 ECharts 实时图表（吞吐走势图、出海语种词库分布环、抽检样品累计走势图、质检纠错对比瀑布图、多语言交付堆叠条形图）。
- 🛡️ **100% 格式符号严格守恒与占位符保护**：
  - 绝不篡改任何代码变量：`[fighterName:1]`、`%s` 等变量 100% 还原保护。
  - 严格保持原文标点符号：顿号编号规范（`1、`、`2、`）、特殊书名号/括号（`【】`）、间隔号（`·`）、乘号（`×`）、冒号（`：`）、波浪号（`～`）。
  - 颜色标签严格对齐闭合：自动修复 `<color=...></color>` 异常空格或拼写，确保游戏端渲染不报错。
- 🔍 **智能质检与问题纠错中心**：
  - 智能诊断中文字符残留、占位符篡改、编号顿号失配、标签数量不符等问题。
  - **异常标红定位**：在界面直观标红问题所在，提供格式严格预置的建议译文，支持在线直接微调并一键应用。
  - 一键执行智能纠错，彻底达到 **0 缺陷、质量完美** 交付。
- 📦 **多项目物理级隔离管理器（Multi-Project Sandbox）**：
  - 每个出海项目独立分配 `memory_db/`、`uploads/`、`outputs/` 目录。
  - 支持多游戏项目动态切换、独立记忆积累，彻底杜绝项目间词汇交叉污染。
- 🌐 **多端支持与外网持久化部署**：
  - 支持本机 `127.0.0.1` 极速访问、局域网协同办公。
  - 内置开箱即用的外网访问与云端 24H 持续运行配置方案。

## 🚀 快速启动

### 1. 环境准备
确保本机已安装 Python 3.8+ 环境，并安装依赖：
```bash
pip install fastapi uvicorn openpyxl python-multipart requests
```

### 2. 一键启动工作台
双击运行根目录下的启动脚本：
```bash
启动无极仙途国际化翻译工作台.bat
```
或在终端执行：
```bash
python workbench\launch.py
```

### 3. 打开浏览器访问
- 本机访问：`http://127.0.0.1:8000`
- 局域网访问：`http://<您的本机局域网IP>:8000`
