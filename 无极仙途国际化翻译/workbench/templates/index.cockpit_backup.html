24小时外网免开机访问部署方案

电脑关机也能随时随地用手机、外地电脑打开翻译大数据平台

重要原理说明： 当您将个人电脑关机时，电脑硬件断电停止运算，任何安装在本机的内网穿透（如花生壳、cpolar等）都会随之停止。要实现真正的“电脑关机后依然能24小时外网访问”，最稳定优雅的方式是将其托管在云端。
方案一：零维护一键云容器托管 (推荐 Railway / Zeabur / Render)

本工作台已为您生成了标准的 Dockerfile 与 requirements.txt。

  1. 将 workbench 目录上传到 GitHub 或直接拖入 Zeabur / Railway 平台。
  2. 平台将自动构建并在几十秒内分配给您一个永久的公网域名（例如 https://wuji-translate.zeabur.app）。
  3. 无论您的电脑开机还是关机，团队所有人均可 24 小时随时访问并上传文件！
方案二：部署到已有云服务器 (腾讯云 / 阿里云 / AWS)

在任意 Linux 云服务器上运行单行命令即可后台常驻：

docker-compose up -d --build
