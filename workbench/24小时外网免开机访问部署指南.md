# 无极仙途国际化翻译工作台 - 24小时外网免开机访问部署指南

---

## 📌 核心原理解析：为什么不能只靠本机软件？

当您将个人电脑**关闭电源（关机或休眠）**时：
- 电脑主板、CPU、硬盘和网卡全部断电停止运作；
- 任何安装在本机上的内网穿透工具（如 cpolar、花生壳、ngrok 等）都会随之**彻底中断**。

因此，要想实现 **“电脑关机后，依然能随时随地用手机、外地电脑 24 小时访问工作台”**，唯一的行业标准解决方案是：**将工作台部署在云端服务器或云托管平台中**。

为此，本工作台已为您准备好全套容器化配置（`Dockerfile`、`docker-compose.yml`、`requirements.txt`），无需繁杂配置，几分钟即可完成全球访问部署。

---

## 🚀 方案一：零运维 1 键云托管（强烈推荐 · 最简单最快）

适合没有云服务器、不想配置 Linux 环境的同学。推荐使用 **Zeabur**（全中文界面，支持国内访问，极速部署）或 **Railway / Render**。

### 部署步骤（以 Zeabur 为例，2分钟搞定）：
1. **准备代码**：
   - 将 `F:\项目\无极国际版\workbench` 目录上传到您的个人 GitHub 私有/公开仓库；
   - 或者直接将 `workbench` 文件夹打包为 zip。
2. **登录平台**：
   - 打开 [Zeabur 官网 (https://zeabur.com)](https://zeabur.com)，微信或 GitHub 一键登录。
3. **创建服务**：
   - 点击 **「创建项目」** -> **「部署新服务」** -> 选择 **「GitHub 仓库」**（选中刚才上传的仓库）。
4. **自动上线**：
   - Zeabur 会自动识别里面的 `Dockerfile` 并自动构建启动（耗时约 30~60 秒）。
   - 在项目设置中点击 **「生成域名」**，即可获得一个永久免费的 HTTPS 网址，例如：
     ```text
     https://wuji-translate.zeabur.app
     ```
5. **体验效果**：
   - 现在，无论您在家里、公司还是外出用手机，甚至个人电脑断电关机，打开该网址即可正常使用工作台上传、翻译和下载！

---

## 🖥️ 方案二：部署到公司/个人已有的云服务器 (阿里云 / 腾讯云 / 华为云)

如果您或团队已有 Linux 云服务器（已安装 Docker）：

1. **上传工作台代码**：
   将 `workbench` 文件夹上传到云服务器任意目录，例如 `/data/wuji-translate`。
2. **后台常驻启动**：
   在服务器终端中进入该目录并运行：
   ```bash
   cd /data/wuji-translate
   docker-compose up -d --build
   ```
3. **配置安全组端口**：
   在云服务器控制台（如腾讯云/阿里云安全组规则），放行 `8000` 端口。
4. **访问工作台**：
   在浏览器输入：
   ```text
   http://你的云服务器公网IP:8000
   ```
   即可 24 小时随时访问，完全独立于个人电脑。

## 💻 方案三：本机开机时局域网免安装访问 (开机即用)

当您在本机办公、电脑开机时：
1. 双击运行 `启动无极仙途国际化翻译工作台.bat`。
2. 工作台启动后会自动输出局域网 IP，例如：
   ```text
   http://192.168.1.108:8000
   ```
3. 只要在同一个公司 WiFi 或路由器下的同事，无需在其电脑上安装任何 Python 或脚本，直接在浏览器打开该 IP 地址即可协同使用。
